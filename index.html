Publicar de verdade no seu Instagram

Configuração feita uma vez só, em uns 30 minutos. Depois disso, cada story é só baixar o arquivo e soltar na pasta fila: o robô publica no horário. Marque cada passo quando terminar.

Parte 1 · Instagram (5 min)

Deixe a conta comercial e pública

No app do Instagram: Configurações → Tipo de conta e ferramentas → Mudar para conta profissional → Empresa. A conta precisa estar pública. Conta de criador não publica stories pela API.

Parte 2 · App gratuito na Meta (10 min)

Crie o app

Entre em developers.facebook.com/apps com seu Facebook → Criar app → caso de uso Gerenciar mensagens e conteúdo no Instagram → nome Story Pronto → criar.

Coloque as 3 contas na sua empresa da Meta

Entre em business.facebook.com/settings (empresa Growth Academy) → Contas → Contas do Instagram → Adicionar e entre com cada conta: growthacademyedu, poloead360 e uninterfortalezacentrooficial.

Clique em cada conta da lista e anote o número de ID dela (normalmente começa com 1784). É o ID que vai para o GitHub.

Gere o token que não vence

No app: Casos de uso → Personalizar → API setup with Unified login → Criar nova configuração e conclua com as opções sugeridas.

Depois, em business.facebook.com/settings: Usuários → Usuários do sistema → Adicionar (nome robo-stories, função Administrador) → Atribuir ativos: as 3 contas do Instagram com controle total e o app Story Pronto → Gerar novo token → app Story Pronto, validade Nunca, permissões instagram_basic, instagram_content_publish e business_management → Gerar.

Um único token serve para as 3 contas e não vence. Copie e guarde: ele aparece uma vez só.

O token é como uma senha do seu Instagram. Não mande para ninguém, nem cole em conversas.

Parte 3 · O robô no GitHub (10 min)

Crie o repositório

Crie uma conta grátis em github.com. Depois: New repository → nome story-publicador → marque Public → Create repository.

Precisa ser público porque a Meta busca a arte por um link aberto. Seus stories já são públicos no Instagram, então nada muda.

Crie os arquivos do robô

No repositório: Add file → Create new file. Para cada arquivo abaixo, digite o nome exatamente como está, cole o conteúdo e clique em Commit changes.

publicar.py
.github/workflows/publicar.yml
fila/leia-me.txt

Guarde o token no cofre do GitHub

No repositório: Settings → Secrets and variables → Actions → New repository secret. Crie 6 segredos, dois por conta. Nos 3 IG_TOKEN_ cole o mesmo token do passo 4; em cada IG_USER_ID_ cole o ID da conta (passo 3):

@growthacademyedu
IG_TOKEN_GROWTHACADEMYEDU
IG_USER_ID_GROWTHACADEMYEDU
@poloead360
IG_TOKEN_POLOEAD360
IG_USER_ID_POLOEAD360
@uninterfortalezacentrooficial
IG_TOKEN_UNINTERFORTALEZACENTROOFICIAL
IG_USER_ID_UNINTERFORTALEZACENTROOFICIAL

Ali o token fica guardado em segredo: nem quem abre o repositório consegue ver.

Parte 4 · Primeiro post

Baixe a arte

No Editor, monte o story e, no passo 3, toque em Baixar para publicar sem agendar. Na janela que abre, escolha a conta. O arquivo sai com nome como poloead360__agora_story-xxxx.jpg: a primeira parte diz a conta, e "agora" faz o robô publicar na hora. Se agendar antes de baixar, o nome leva a data e a hora, e ele publica no horário.

Solte na pasta fila

No GitHub, abra a pasta fila → Add file → Upload files → arraste o arquivo → Commit changes. O robô começa a rodar sozinho em até 1 minuto.

Confira

Na aba Actions do repositório aparece a rodada: verde é sucesso. O story aparece no seu Instagram, e o arquivo vai para a pasta publicados. Se algo der errado, o arquivo vai para erros com um .txt explicando o motivo.

Parte 5 · Enviar sem abrir o GitHub

Ligue o botão Robô

No alto, clique em Robô, cole uma chave do GitHub (o passo a passo está dentro da janela) e clique em Salvar e testar. A partir daí, ao exportar, aparece Publicar no Instagram: um clique e o story vai para a fila, com o nome certo. Na mesma janela você vê o que está na fila e pode cancelar.

Funciona no arquivo HTML aberto no Chrome ou Edge do computador. A chave fica salva só naquele navegador.

Bom saber

  • O robô verifica a fila a cada 10 minutos. O GitHub às vezes atrasa alguns minutos nos horários de pico.
  • Imagem precisa ser JPG (o editor já baixa assim) e vídeo MP4 de 3 a 60 segundos.
  • Adesivo de link não vai pela API. Para link clicável, use o modo "Link no direct" ou poste esse story pelo celular.
  • O token do usuário do sistema não vence. Se um dia você gerar outro no passo 4, atualize os segredos IG_TOKEN_.
  • Se faltar o token de uma conta, os arquivos dela esperam na fila e as outras contas seguem publicando normalmente.

Do protótipo ao produto

  1. Conectar a conta. O cliente faz login com Facebook/Instagram (OAuth da Meta). A conta precisa ser Comercial e o app precisa das permissões de publicação aprovadas pela Meta.
  2. Editar e salvar. Este editor gera a imagem ou o vídeo 1080×1920 com textos e link gravados. Ao agendar, o arquivo sobe para um armazenamento com URL pública (S3, Cloudflare R2, Supabase Storage).
  3. Vídeo no servidor. Para não depender do celular do cliente, o servidor refaz a montagem com FFmpeg (vídeo original + camada PNG de textos) e entrega MP4 H.264/AAC, o formato que o Instagram aceita.
  4. Fila no servidor. Banco guarda story_id, conta, imagem_url, publicar_em, status. Um agendador (cron a cada minuto) busca o que venceu.
  5. Publicar via API. Cria o contêiner com media_type=STORIES e a URL da imagem, depois chama media_publish. Status vira "publicado" e o cliente recebe aviso.
  6. Link clicável. A API não publica adesivos. Três modos por story: lembrete no celular (o cliente cola o adesivo e publica em segundos), automático + direct (o story pede uma palavra e a API de mensagens envia o link clicável no direct) ou automático sem link (aponta para o link da bio).
